### Почему значение памяти может немного изменяться
Значение памяти постоянно колеблется, так как в C# автоматически работает сборщик мусора, который в случайные моменты времени очищает ОЗУ от неиспользуемых объектов. Кроме того, операционная система непрерывно перераспределяет ресурсы между всеми процессами в фоне.
